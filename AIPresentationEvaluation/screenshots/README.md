# Screenshotok

Ebbe a mappába kerülnek az AI eszközök felületéről készített képernyőképek, különösen ha a kimenet vizuálisan formázott (pl. Google AI Studio canvas nézet, Gemini dokumentum mód, ChatGPT formázott válasz).

## Fájlnév-konvenció

```
<eszköz>_<forrásanyag>_<prompt_típus>.png
```

Példák:
- `gemini_sample_source_text_4_design.png`
- `chatgpt_digitalis_transzformacio_2_strukturalt.png`
- `google_ai_studio_sample_source_text_1_baseline.png`

## Mikor érdemes screenshotot készíteni?

- Ha az AI vizuálisan elrendezett választ ad (táblázatok, formázott listák)
- Ha a kimenet valamilyen speciális megjelenítésű (canvas, doc nézet)
- Ha a prompt vagy a beállítások is fontosak a reprodukálhatóság szempontjából
- Ha az AI diagramot, infografikát vagy képjavaslatot rajzol / jelenít meg

## Állapot

A mappa jelenleg üres – a kísérletek elvégzése után kerülnek ide a screenshotok.
